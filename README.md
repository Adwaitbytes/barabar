# Barabar

**AI Finance Controller for Razorpay merchants.** Reconciles Razorpay settlements, the bank statement and the sales ledger to the paise; explains every unmatched rupee with a typed exception; drafts the journal entries; answers *"why did ₹1,83,412 land in my bank?"* with a proof tree.

Deterministic where money is decided. AI only on the tail.

> Build in progress — see `docs/` for architecture, decisions and the honest failure log.
